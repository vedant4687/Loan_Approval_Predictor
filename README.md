# 💰 Loan Approval Predictor

A Machine Learning project that predicts loan approval based on applicant information using classification algorithms.

---

## ✨ Features

- Loan Approval Prediction
- Data Cleaning
- Feature Engineering
- Machine Learning Classification
- User-friendly Interface

---

## 🛠️ Technologies

- Python
- Scikit-Learn
- Pandas
- NumPy
- Streamlit

---

## 📊 Dataset

Loan Approval Dataset

---

## 🚀 Installation

```bash
git clone https://github.com/vedant4687/Loan_Approval_Predictor.git

cd Loan_Approval_Predictor

pip install -r requirements.txt
```

---

## ▶️ Run

```bash
streamlit run app.py
```
